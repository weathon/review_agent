================================================================================
QUICK CRITIQUE REFERENCE: SFT PAPER WEAKNESSES
================================================================================

PAPER: "SFT Without Overfitting: Analyzing the Training Dynamics of Supervised Fine-Tuning"
CLAIMS: Attention-only fine-tuning preserves OOD generalization better than full/FNN-only fine-tuning

================================================================================
DIRECT CONTRADICTIONS FROM RELATED PAPERS:
================================================================================

1. FORGETTING MECHANISM MISUNDERSTOOD (CRITICAL)
   Source: Function Vector analysis (catastrophic forgetting paper)
   Problem: Paper assumes freezing FNNs prevents knowledge loss
   Reality: Forgetting stems from ACTIVATION BIAS, not parameter overwriting
   Impact: Fine-tuned attention heads cause FNN activation drift regardless

2. ATTENTION DRIFT PHENOMENON NOT ADDRESSED (CRITICAL)
   Source: Knowledge editing paper (50%+ specificity failure rate)
   Problem: Selective fine-tuning creates "Attention Drift" in 50%+ cases
   Reality: Fine-tuned attention heads overly focus on task-specific patterns
   Impact: OOD examples misinterpreted due to calibration drift

3. CLAIMS NOT GENERALIZABLE (CRITICAL)
   Source: Function Vector paper + TIC-LM
   Problem: Results claimed universal, but tested on 1-2 task types only
   Reality: Forgetting patterns are model-dependent AND task-dependent
   Impact: Conclusion (attention > FNN > full) may only hold for reasoning tasks

4. MECHANISTIC UNDERSTANDING ABSENT (CRITICAL)
   Source: Function Vector framework available but not used
   Problem: No analysis of WHICH attention heads change during fine-tuning
   Reality: Cannot validate claims without mechanism analysis
   Impact: "Preservation" claim is unvalidated speculation

================================================================================
EVALUATION GAPS:
================================================================================

5. NO FORWARD TRANSFER vs. FORGETTING SEPARATION
   → Gains could come from task-specific overfitting, not true OOD preservation

6. NO TEMPORAL STABILITY EVALUATION
   → TIC-LM shows different task domains need different methods
   → No evidence strategy works on sequential/continual learning

7. OOD EVALUATION INSUFFICIENT
   → Knowledge editing: standard metrics miss specificity failures
   → Test sets may be in-distribution relative to pre-training
   → No paraphrased variants, edge cases, or adversarial examples

8. DOWNSTREAM CORRUPTION NOT MEASURED
   → Knowledge editing: selective edits corrupt unrelated tasks
   → No evidence fine-tuning doesn't degrade other capabilities

9. MISSING MECHANISTIC ANALYSIS
   → No layer activation distribution analysis
   → No attention head comparison (before/after fine-tuning)
   → No proof frozen FNN representations still work with fine-tuned attention

================================================================================
ARCHITECTURAL ASSUMPTIONS NOT VALIDATED:
================================================================================

10. ATTENTION-FFN COUPLING IGNORED
    Problem: Paper treats layers as independent
    Reality: FFN outputs → attention queries, attention routing → FFN inputs
    Impact: Frozen FNNs become bottlenecks or attention reverts to pre-training

11. NO BASELINE COMPARISONS
    Missing: LoRA, layer-wise scaling, adapter modules
    These have stronger theoretical grounding for selective fine-tuning

================================================================================
EVIDENCE LOCATIONS IN PAPERS FOUND:
================================================================================

TIC-LM (MB53uAZKSc.txt):
  - "different domains evolve at different rates, favoring different methods"
  - Forward transfer / forgetting metrics explicitly separated
  - Data replay trade-offs shown to be domain-dependent

Function Vector (gc8QAQfXv6.txt):
  - "CF in LLMs primarily stems from biases in function activation rather than overwriting"
  - "model forgetting is influenced by both the specific training tasks and models"
  - Function vector extraction methodology for mechanistic analysis

Knowledge Editing (4l3AH8Bhmt.txt):
  - "Attention Drift phenomenon: edited model assigns excessive attention scores to entities"
  - 50%+ specificity failure rate on standard knowledge editing
  - "Specificity Failure" metrics include relational tasks and distracting contexts
  - Evidence that selective parameter edits have broad downstream effects

================================================================================
REVIEWER RECOMMENDATIONS:
================================================================================

MUST HAVE (before acceptance):
- Mechanistic analysis of which attention heads change
- Evaluation on multiple task domains/types
- True OOD tests with distributional shift (not just test sets)
- Forward transfer and forgetting prevention measured separately

SHOULD HAVE (to strengthen):
- Temporal/sequential learning evaluation (TIC-LM style)
- Downstream task corruption analysis (knowledge editing style)
- Comparison to LoRA, adapters, layer-scaling baselines
- Analysis of attention-FFN activation patterns during fine-tuning

SUSPICIOUS FINDINGS:
- Claims of universal superiority from 1-2 task evaluations
- No analysis of mechanism despite claiming preservation
- Comparison baselines (full FT, FNN-only) may not be properly tuned
- OOD generalization not properly defined

================================================================================
MOST POWERFUL SINGLE CRITIQUE:
================================================================================

"The paper's central claim—that attention-only fine-tuning preserves OOD
generalization—rests on a misunderstanding of the forgetting mechanism. Recent
work (Function Vector analysis) shows forgetting stems from ACTIVATION BIAS,
not parameter overwriting. Freezing FFN layers does NOT prevent activation
drift in attention heads. The paper provides no mechanistic analysis of
attention head changes, no measurement of specificity failures (documented in
50%+ of similar selective edits), and no evidence the strategy generalizes
beyond the narrow task domain evaluated. Without this, the core claim is
unfounded."
