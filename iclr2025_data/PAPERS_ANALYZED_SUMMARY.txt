## Key Findings Summary

### Dominant Themes in Empirical Studies:

1. **Out-of-Distribution Generalization Failures**
   - Consistent across papers analyzing scaling/extrapolation
   - Performance degrades as OOD distance increases
   - Models struggle with complexity beyond training

2. **Architecture and Model Size Dependency**
   - Results not universal across depths, architectures
   - Positional embeddings critical for generalization
   - Modern architectures underperform classical ones in some tasks

3. **Methodological Sensitivity**
   - Task formulation heavily influences results
   - Data augmentation choices critical
   - Hyperparameter tuning required per setting

4. **Limited Theoretical Grounding**
   - Methods work empirically but lack formal guarantees
   - Assumptions validated only empirically
   - Post-hoc constraints added without theoretical justification

5. **Benchmark and Data Dependencies**
   - Findings don't uniformly transfer across benchmarks
   - Data curation affects results
   - Failure modes are benchmark-specific
