## Summary

TokenCount proposes a training-free object counting framework that repurposes SAM without architectural modifications or auxiliary models. It introduces two components: (1) probabilistic prompt generation that iteratively expands from high-confidence regions using SAM's image embedding similarity, and (2) output token-based verification using SAM's decoder output tokens with the TS-SS hybrid metric to distinguish positive from negative instances. The method achieves competitive results within the "SAM only" category on FSC-147 and strong results on CARPK.

## Strengths

- **Output token-based verification is a genuinely useful insight**: Table 5 shows the output token space achieves MAE 16.25 versus 16.94 in the image embedding space on FSC-147. Figure 5's PCA visualization provides intuitive qualitative evidence that output tokens form well-separated clusters for positive/negative instances while image embeddings produce overlapping distributions. This directly validates the core idea that SAM's output tokens are more discriminative for counting than image embeddings.

- **Best-in-class among "SAM only" methods**: On FSC-147, the method achieves MAE 16.25, substantially outperforming prior SAM-only methods TFOC (19.95), Count-Anything (27.97), and plain SAM (42.48) (Table 1). This is a meaningful advance for the efficiency-constrained setting that avoids auxiliary models.

- **Strong CARPK results**: On CARPK, MAE 4.68 outperforms all training-based methods (BMNet+ 5.76, SAFECount 5.33, LOCA 9.97) and is competitive with TFCAC (4.39) (Table 1). This demonstrates the method's effectiveness on consistent-viewpoint, clear-boundary scenes.

- **Probabilistic prompt generation is well-motivated**: The iterative probability update (setting verified-positive regions to 0, decreasing verified-negative regions, expanding exemplars) is a sensible design that addresses real limitations of grid/superpixel prompting. Table 4 shows consistent MAE improvement as prompts per iteration increase from 32 to 128.

- **Well-structured ablation design**: Tables 3, 4, and 5 isolate the contributions of the verification metric, prompt generation parameters, and representation space respectively, making each design choice independently evaluable.

## Weaknesses

### Fatal

None.

### Major

- **Abstract claims are directly contradicted by Table 1**: The abstract states the method achieves "superior accuracy... outperforming existing training-based and training-free counting methods." Table 1 shows multiple methods outperform it: LOCA (10.79), PseCo (13.05), TFCAC (12.26), SAFECount (14.32), BMNet+ (14.62). The method outperforms *some* prior methods, not *existing* methods generally. The body text is more careful ("best performance among training-free SAM only methods"), but the abstract, which is the most widely read section, makes a clearly false claim. The same abstract also states "comparable performance to training-free approaches that require additional models," but TFCAC (12.26) vs. their 16.25 represents a 32% MAE gap — "comparable" is a significant overstatement.

- **TS-SS "breakthrough" narrative is unsupported by the magnitude of improvement**: Section 3.2 claims "nonhybrid metrics have reached a performance plateau" and that TS-SS "breaks through this barrier." But Table 3 shows TS-SS (16.25) improves over cosine similarity (16.48) by only 0.23 MAE and over L2 distance (16.53) by 0.28 MAE — marginal differences with no variance or significance testing reported. The actual large gain comes from switching from dot product (19.58) to cosine/L2 (16.48/16.53), which the paper's narrative does not acknowledge. This means the core methodological contribution (the hybrid metric) provides negligible improvement over a standard metric, while the representation change (output tokens vs. image embeddings, Table 5, 0.69 MAE improvement) does the real work.

- **Unresolved tension between the motivation and the method design**: The paper's central motivation is that "the inherent uncertainty of the similarity metric derived from [SAM's] image encoder" makes image-embedding-based verification unreliable. Yet the probabilistic prompt generation stage (Eq. 1) computes its probability distribution directly from cosine similarity between the SAM image embedding and the exemplar embedding — the very signal the paper claims is inadequate. If image embedding similarity is reliable enough to drive the entire search process, the argument that output tokens are *necessary* for verification is weakened. The paper needs to explicitly address why image embedding similarity suffices for coarse localization but not for verification.

### Minor

- **RMSE is dramatically worse than baselines relative to MAE**: The method's RMSE of 133.11 on FSC-147 is far worse than LOCA (56.97), SAFECount (85.54), and BMNet+ (91.83), despite competitive MAE (16.25). This discrepancy suggests catastrophic failures on a subset of images (large outlier errors). The paper never discusses this, which would be important for understanding the method's reliability profile.

- **CARPK uses a non-standard evaluation protocol**: The paper uses "12 objects from the training set to use as exemplars" for CARPK, whereas FSC-147 uses 3 exemplars from the test image. The number 12 is not justified, and this asymmetry may inflate CARPK performance relative to baselines that follow different protocols, making the "outperforming all supervised methods" claim on CARPK potentially misleading.

- **Overclaiming in Table 5 interpretation**: The paper states the 0.69 MAE difference between output tokens (16.25) and image embeddings (16.94) "proves our claim is accurate." A 0.69 MAE difference on a single benchmark with no variance estimates is suggestive but not probative — "supports" or "is consistent with" would be appropriate language.

## Novel Insights

The most interesting observation across the reviews is that the paper's two components have asymmetric empirical support: the output token representation change (Table 5) provides the meaningful improvement (0.69 MAE), while the heavily-motivated TS-SS metric contributes only a marginal 0.23 MAE over cosine similarity. This suggests the paper's theoretical narrative about "dual-natured" tokens requiring a hybrid metric is post-hoc rationalization rather than the actual source of improvement. The real insight — that SAM's output tokens are more discriminative than image embeddings for counting — could have been demonstrated with simpler metrics and a cleaner presentation.
