## Summary

MERLIM is a large-scale multi-modal evaluation benchmark (300K+ image-question pairs) for assessing Instruction-Tuning Large Vision-Language Models (IT-LVLMs) on fundamental computer vision tasks: object recognition, inter-object relationship understanding, and object counting. The central technical contribution is a methodology for detecting "hidden hallucinations" — cases where a model appears to correctly identify an object but the answer lacks genuine visual grounding — achieved by using image inpainting to remove object instances and then comparing model outputs before and after the edit.

---

## Strengths

- **Novel hallucination taxonomy**: The distinction between "regular hallucinations" (false positives against ground truth) and "hidden hallucinations" (apparently correct predictions that survive inpainting removal) is a genuinely useful conceptual contribution. The counterfactual inpainting methodology to operationalize this is elegant and provides empirical evidence that high-performing models gain accuracy through language shortcuts, not visual grounding.
- **Scale and breadth**: 300K+ image-question pairs, 11 diverse IT-LVLMs evaluated, three task types, multiple prompts per task, and both original/edited image sets. The benchmark is built on well-established datasets (MS-COCO, LVIS, Visual Genome), making it grounded and extensible.
- **Prompt sensitivity analysis**: Demonstrating that semantically equivalent prompts elicit substantially different model outputs (up to ~26% F1 variance in xGen-MM) is a practically important and underappreciated finding, well-illustrated in Figure 2.
- **LLM vs. IT-LVLM comparison**: Including a language-only baseline to quantify how much performance is attributable to language priors is a sound methodological choice that strengthens the bias analysis.

## Weaknesses

### Fatal
*(None)*

### Major

- **Inpainting validity is underexamined**: The entire "hidden hallucination" methodology hinges on inpainted images being perceptually valid. If inpainting leaves visible artifacts (blurs, color discontinuities), models could plausibly respond differently simply due to image degradation rather than lost semantic grounding. This analysis is relegated to supplementary material, but it is the central empirical assumption of the paper and should be addressed thoroughly in the main text with quantitative quality metrics (e.g., FID, LPIPS, human preference study).

- **Evaluation pipeline reliability**: Object recognition scoring relies on spaCy POS tagging → WordNet synonyms → ChatGPT API synonym expansion. Each step introduces noise. The spaCy step can misclassify multi-word entities or compound nouns; WordNet synonym chains can over-match (e.g., "vehicle" matching "car"). While the authors pre-cache ChatGPT outputs, there is no ablation showing how sensitive results are to these parsing choices. Given scores as low as 20-48% F1, it is unclear whether low scores reflect genuine model failure or parsing pipeline errors.

- **Outdated model coverage**: For an ICLR 2025 submission, there is a conspicuous absence of GPT-4V, LLaVA-1.6/NeXT, InstructBLIP-2, Otter, mPLUG-Owl2, and other widely-used 2023–2024 models. All Vicuna-based models use v0/v1.1, which are outdated. The benchmark's diagnostic value is diminished if it does not cover models that practitioners currently use.

- **"Hidden hallucination" concept conflates confounding cases**: The framework does not clearly separate three importantly different scenarios: (a) language prior hallucination (the model never attended to the removed object), (b) context inference (the model correctly infers "tennis racquet" from "tennis court" context, which is semantically reasonable), and (c) global scene holistic reasoning. Labeling case (b) as a "hallucination" is debatable and may unfairly penalize models with strong commonsense visual reasoning.

### Minor

- The claim that BLIP-2's consistency across prompts "might stem from its lacking an instruction-aware Q-former module" is speculative and not tested empirically. An ablation would strengthen this hypothesis.
- In Table 2, Kosmos-2 achieves >90% Acc_neg but only ~5–19% Acc_org, suggesting it almost always answers "No." This biased response pattern should be flagged more explicitly as a failure mode rather than a positive result.
- The counting task subsection is comparatively underanalyzed: only MAE and yes/no follow-up consistency are reported, but there is no breakdown by object category or count range to understand where models fail systematically.
- There are unexplained superscript artifacts throughout (e.g., "IT-LVLMs^AUQ", "hidden hallucinations^4cSE", "300,664^IAUQ"), suggesting PDF conversion issues and careless proofreading.

### Tiny

- "IT-LVLM" and "IT-LVLM" are sometimes misrendered as "IT-LVML" in the abstract (typo).
- No statistical significance testing is presented for any pairwise model comparison.

## Nice-to-Haves

- A smaller "canonical" subset (e.g., 10K balanced image-question pairs) that is publicly validated for fast model development would increase adoption.
- Including an experiment that directly controls for context plausibility (e.g., comparing hallucination rates for contextually plausible vs. implausible removed objects) would sharpen the hidden hallucination finding.

---

## Novel Insights

The most genuinely novel insight is the "hidden hallucination" framing: models that perform *best* on standard benchmarks may be doing so *because* they hallucinate plausible objects from language and scene context, not in spite of it. The empirical result that precision drops most for the highest-performing models when objects are removed (Figure 3) is a counterintuitive and consequential finding. The supplementary gradient attribution analysis, which suggests that previously-generated language tokens carry larger gradients than the image tokens, provides mechanistic support. If robustly validated, this suggests that standard benchmark performance may be systematically inflated by language-prior exploitation, and that visual grounding must be measured independently of final output accuracy — a methodologically important point for the evaluation community.

---

## Suggestions

1. **Validate inpainting quality quantitatively** in the main text, with human annotation studies and automatic perceptual metrics, and report per-category inpainting failure rates.
2. **Add GPT-4V and LLaVA-1.6/NeXT** as model baselines to make results relevant to the 2024–2025 research landscape.
3. **Stratify "hidden hallucinations" by contextual plausibility** of the removed object (e.g., "tennis racquet in a tennis scene" vs. "clock in a bedroom") to disentangle valid commonsense reasoning from LLM hallucination.
4. **Ablate the NLP parsing pipeline** — report benchmark scores using only exact string matching, only spaCy+WordNet, and the full ChatGPT-augmented pipeline — so readers understand how sensitive conclusions are to this choice.
5. **Release a compact evaluation subset** validated by human annotators that can serve as a standard fast-evaluation set.

---

## Final Score

The benchmark addresses a real and important problem, and the hidden hallucination concept is a meaningful conceptual contribution. However, the key empirical methodology (inpainting) is insufficiently validated in the main text, the evaluation pipeline is complex and not adequately ablated, the model coverage is outdated for a 2025 venue, and the hallucination taxonomy conflates distinct failure types. The paper is a reasonable first step but requires substantial revision to be accepted at ICLR.
