## Summary
VN-EGNN proposes extending E(n)-equivariant GNNs (EGNNs) with virtual nodes that carry spatial coordinates, applied to protein binding site identification. The virtual nodes learn abstract neural representations of binding pockets and their coordinates converge to binding site centers via a three-phase heterogeneous message passing scheme. A multi-objective loss combining dice segmentation and binding site center regression is used, and experiments on COACH420, HOLO4K, and PDBbind2020 demonstrate state-of-the-art DCC performance against prior deep learning methods.

---

## Strengths

- **Elegant emergent behavior.** The observation that virtual node coordinates spontaneously converge to binding site centers (even before the explicit center-loss is introduced) is genuinely interesting and strongly motivates the architecture design. This is presented as a key empirical motivation and lends credibility to the approach.

- **Thorough ablation study.** Table 2 isolates contributions of (a) virtual nodes, (b) heterogeneous message passing, and (c) ESM-2 embeddings. Each component adds measurable performance, and the full model consistently outperforms partial configurations on all three benchmarks.

- **Solid theoretical grounding.** Proposition 1 formally proves equivariance of VN-EGNN; the oversquashing analysis using Topping et al.'s Lemma 1 is appropriately scoped and correctly argues that virtual nodes bound shortest-path distance to 2, stabilizing gradients.

- **Competitive performance with reasonable model size.** VN-EGNN (1.2M params) achieves best DCC on all three benchmarks among deep learning models, while using fewer parameters than EquiPocket (1.7M) and relying only on residue-level (α-carbon) information rather than full atom or surface representations.

- **Practical efficiency gains.** Using residue-level representations reduces input graph size substantially compared to atom-level methods, with claimed training time of ~8 hours on 4×A100 GPUs.

---

## Weaknesses

### Fatal
None.

### Major

- **Unfair comparison with P2Rank (different training set).** The dominant baseline, P2Rank, uses a different training set that may overlap with the test benchmarks. This is flagged by footnote (c) but not rectified experimentally—e.g., retraining P2Rank on scPDB under the same split. On the practically important DCA metric, P2Rank outperforms VN-EGNN on both HOLO4K (0.787 vs. 0.659) and PDBbind2020 (0.826 vs. 0.820). The paper's state-of-the-art claim needs careful qualification because the strongest competitor is never put on equal footing.

- **DCA metric on HOLO4K substantially worse than P2Rank.** DCA measures proximity to any ligand atom (arguably the more biologically relevant metric for drug discovery, since it reflects whether the prediction would enable correct docking). VN-EGNN achieves only 0.659 DCA on HOLO4K versus P2Rank's 0.787—a 12.8 percentage point gap that is not adequately discussed or explained.

- **Fibonacci sphere initialization breaks equivariance.** The paper explicitly "relaxes" the equivariant initialization, placing virtual nodes on a Fibonacci grid around the protein. While random rotation is used for data augmentation, this initialization is no longer strictly equivariant, which contradicts the title claim of E(3)-equivariance in practice. The consequences for the equivariance guarantees of Proposition 1 are not explicitly discussed. The paper should clearly distinguish the theoretical property from the practical implementation.

### Minor

- **No virtual-node-to-virtual-node edges.** The paper states virtual nodes are not connected to each other but does not ablate this choice or provide theoretical justification. Connecting virtual nodes might allow them to more efficiently differentiate and avoid converging to the same binding site.

- **SE(3) equivariance claim is weak.** The argument that SE(3) equivariance is achieved through chirality encoding (L- vs. D-amino acids encoded differently) is not a designed architectural property—it is a consequence of the input representation. This is a fragile justification and conflates equivariance of the architecture with properties of the data.

- **Confidence module is borrowed.** The self-confidence module is directly taken from EquiPocket/AlphaFold-style scoring and is not a novel contribution of this work, though it is still useful.

- **No results reported on scPDB.** The training set (scPDB) is used but no in-distribution evaluation is reported, making it harder to assess generalization vs. memorization.

### Tiny

- The abstract claims "new state-of-the-art" on HOLO4K without clarifying that DCA on HOLO4K is not SOTA.
- Table 1 uses bold for P2Rank's DCA on HOLO4K and PDBbind2020, which is correct, but this contradicts the abstract's claim.

---

## Nice-to-Haves

- Retrain P2Rank on the same scPDB training set to enable a direct apples-to-apples comparison—this would either strengthen the paper's SOTA claim or provide an honest assessment.
- Ablate the number/connectivity of virtual nodes (partially addressed in App. L but not in the main paper).
- Report results on the broader Astex Diverse or Chen11 benchmarks to improve generalizability claims.
- Discuss whether the approach generalizes beyond α-carbon residue graphs (e.g., full atom or surface representations).

---

## Novel Insights

The most genuinely novel insight is using virtual nodes in EGNNs with spatial coordinates as *latent geometric entities* that self-organize toward binding site positions—a form of implicit clustering in geometric space that emerges from message passing without explicit architectural bias beyond the training objective. This "coordinate as prediction" paradigm for virtual nodes (as opposed to using them solely as a global aggregation device) could have broader applicability in geometric deep learning tasks where hidden spatial entities need to be inferred from a point cloud.

---

## Suggestions

1. Retrain P2Rank using the same scPDB training split and include it as a baseline for fair comparison.
2. Add an ablation with virtual-node-to-virtual-node edges to clarify the design choice.
3. Explicitly state in the paper body that the Fibonacci initialization is not equivariant and characterize what equivariance guarantee, if any, the full practical system retains.
4. Report DCA results more prominently and provide an explanation for the gap on HOLO4K.
5. Consider adding a comparison with newer binding site methods beyond the EquiPocket benchmark (e.g., SiteMap, AutoSite).

---

## Final Score

The paper presents a well-motivated, clearly executed extension of EGNNs for an important biomedical task. The core idea is elegant, the ablation is solid, and SOTA DCC results are demonstrated. However, the comparison with the main competitor (P2Rank) remains confounded by training set differences, DCA performance on HOLO4K is significantly worse than P2Rank, and the equivariance guarantees in practice are weaker than claimed. This is a good but not exceptional paper.
